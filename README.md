# Учебные проекты, Школа 21 (Проджект-менеджмент)

Здесь собраны проекты, выполненные в рамках обучения по направлению «Проджект-менеджмент». Моя роль в проектах: Project Manager / координатор команды (управление командой из 3 человек).

## 1. Исследование и стратегия развития продукта (Duolingo)
Провела анализ целевой аудитории: сегменты, потребности, проблемы, поведенческие особенности.
Проработала фреймворки Persons и Jobs-to-be-Done.
Координировала команду из 3 человек.
Результат: готовая стратегия развития продукта, презентация защищена.
## 2. User Story Map и бэклог продукта (Duolingo)
Составила User Story Map: путь пользователя по шагам, группировка действий в этапы.
Приоритизировала истории (must / should / could) и выделила релизы.
Результат: User Story Map и бэклог с настроенными статусами.
## 3. Проектная документация и аналитика
Составила документ с требованиями: описание функционала, приоритеты, валидация, риски.
Настроила доску в Asana: декомпозиция задач, статусы, исполнители.
Проанализировала жизненный цикл IT-продукта.
Результат: комплект проектных артефактов.
